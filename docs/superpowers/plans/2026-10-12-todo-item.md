# 待办事项（Todo Item）创建功能实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有 Java + Maven 项目中，为内部用户新增“待办事项”的最小闭环创建能力，支持记录事项名称与描述。

**Architecture:** 采用领域模型 + 仓库 + 应用服务的分层结构。`TodoItem` 作为不可变领域对象，负责字段约束与值对象行为；`TodoRepository` 定义持久化端口，内存实现提供最小可测试存储；`TodoService` 封装创建用例，协调校验与持久化。后续如需替换为数据库或 Web 入口，只需新增适配器，无需改动核心。

**Tech Stack:** Java 17, Maven, JUnit 5, AssertJ

## Global Constraints

- JDK 版本：`maven.compiler.source/target = 17`
- 构建工具：Maven（`pom.xml` 已存在）
- 测试框架：JUnit 5.10.2 + AssertJ 3.26.0
- 目标用户：内部用户
- 最小闭环：仅实现“新增待办事项”，不涉及编辑、删除、完成状态、权限、持久化到数据库
- 输入字段：事项名称（name）和描述（description）
- 代码风格：沿用 `com.antdigital.*` 包结构，类注释使用中文

```java
package com.antdigital.todo;

import java.time.Instant;
import java.util.Objects;
import java.util.UUID;

/**
 * 待办事项领域实体
 *
 * @author aiwork
 * @date 2026/10/12
 */
public final class TodoItem {

    private final String id;
    private final String name;
    private final String description;
    private final Instant createdAt;

    /**
     * 构造待办事项
     *
     * @param name        事项名称，不能为空或仅含空白
     * @param description 事项描述，可为 null
     */
    public TodoItem(String name, String description) {
        if (name == null || name.isBlank()) {
            throw new IllegalArgumentException("事项名称不能为空");
        }
        this.id = UUID.randomUUID().toString();
        this.name = name.trim();
        this.description = description == null ? "" : description.trim();
        this.createdAt = Instant.now();
    }

    public String getId() {
        return id;
    }

    public String getName() {
        return name;
    }

    public String getDescription() {
        return description;
    }

    public Instant getCreatedAt() {
        return createdAt;
    }
}
```

```java
package com.antdigital.todo;

import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

/**
 * 内存待办事项仓库实现
 *
 * @author aiwork
 * @date 2026/10/12
 */
public class InMemoryTodoRepository implements TodoRepository {

    private final List<TodoItem> store = new ArrayList<>();

    @Override
    public TodoItem save(TodoItem item) {
        store.add(item);
        return item;
    }

    @Override
    public List<TodoItem> findAll() {
        return new ArrayList<>(store);
    }
}
```

```java
package com.antdigital.todo;

/**
 * 待办事项应用服务
 *
 * @author aiwork
 * @date 2026/10/12
 */
public class TodoService {

    private final TodoRepository repository;

    /**
     * 构造应用服务
     *
     * @param repository 待办事项仓库
     */
    public TodoService(TodoRepository repository) {
        this.repository = repository;
    }

    /**
     * 创建新的待办事项
     *
     * @param name        事项名称，不能为空或仅含空白
     * @param description 事项描述，可为 null
     * @return 创建并保存后的待办事项
     */
    public TodoItem createTodo(String name, String description) {
        TodoItem item = new TodoItem(name, description);
        return repository.save(item);
    }
}
```
